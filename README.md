# 🚀 SkillBridge - Job Portal

**SkillBridge** is a full-stack MERN job portal web application that connects job seekers with employers. It features secure authentication, role-based access, job postings, file uploads with Multer, and Cloudinary integration for storing resumes or images.

> ⚡ *Note: This project is not affiliated with the official U.S. DoD SkillBridge program. ‘SkillBridge’ here refers to this independent job portal project.*

---

## 📌 Features

- ✅ User registration & secure login (JWT + cookies)
- ✅ Role-based access: Admin, Company, Job Seeker
- ✅ Companies can post & manage job listings
- ✅ Job seekers can search & apply for jobs
- ✅ Upload resumes/files (Multer + Cloudinary)
- ✅ Track applications status
- ✅ RESTful API built with Express.js
- ✅ MongoDB Atlas for cloud database
- ✅ Responsive frontend built with React.js
- ✅ Deployed on Vercel (frontend) & Render (backend)

---

## 🛠️ Tech Stack

- **Frontend:** React.js (Vite)
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas, Mongoose
- **Authentication:** JWT, Cookies
- **File Uploads:** Multer
- **Cloud Storage:** Cloudinary
- **Others:** CORS, Dotenv
